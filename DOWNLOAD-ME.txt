Aether64 Quest 2 Demo

The APK is the file named:
    Aether64-Quest2-debug.apk

Install it with SideQuest, or from Android platform-tools:
    adb install -r Aether64-Quest2-debug.apk

Do not open the APK directly from the Quest Browser. Download this ZIP to a computer first.

The .cpp files are the native C++ OpenXR renderer and engine. The Android launcher is in:
    android/app/src/main/java/org/aether64/xr/AetherActivity.java
